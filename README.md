# Employee Management System

A console-based Employee Management System developed using Java, JDBC, and MySQL. The project demonstrates database connectivity, CRUD operations, DAO architecture, and resource management using try-with-resources.

## Features

- Add new employees
- View all employees
- Search employee by ID
- Update employee salary
- Delete employees
- MySQL database integration
- PreparedStatement for SQL operations
- DAO-based architecture
- Try-with-resources for automatic resource management
- Exception handling

## Technologies Used

- Java
- JDBC
- MySQL
- SQL
- VS Code
- Git & GitHub
